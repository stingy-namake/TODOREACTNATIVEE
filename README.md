## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run the app
npm run web
```

## 📱 How It Works

1. App opens with a welcome screen
2. Click **"GO"** to access your todo list
3. Start managing your tasks!

## ✨ Features

- ➕ **Add** new tasks
- ✏️ **Edit** existing tasks
- 🗑️ **Delete** completed tasks
- 🎯 Simple, intuitive interface
